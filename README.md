# EcoGrid

EcoGrid е фронтенд демонстрација на еколошка апликација што ги поврзува граѓаните, општините и компаниите. Состојбата се зачувува локално во `localStorage` под клучот `ecogrid-demo-v1`, а преку демо-прекинувачот може да се следи како пријавите, општинските налози, известувањата, еко-акциите и ваучерите се поврзани меѓу трите профили. Прикажаните податоци, регистрацијата, најавата, гласањето, ваучерите, рекламите и верификацијата се симулирани; нема сервер, вистинско плаќање или реални реклами.

## Почеток

```bash
npm install
npm run dev
```

## Проверка и продукциска верзија

```bash
npm run lint
npm run build
npm run preview
```

## Објавување на GitHub Pages

Репозиториумот е подготвен за автоматско објавување преку GitHub Actions. Постави го проектот во репозиториум со главна гранка `main`, отвори **Settings → Pages**, избери **GitHub Actions** како извор и стартувај го workflow-от **Deploy EcoGrid to GitHub Pages**. Секое следно ажурирање на `main` автоматски ја објавува новата верзија. URL-то ќе биде `https://<корисничко-име>.github.io/<име-на-репозиториум>/`.

## Демонстрациски тек

Започни со граѓанскиот профил: оди низ Еко Академијата, пријави место на Еко Картата, гласај, подигни партнерски ваучер и прегледај ги известувањата. Потоа избери „Општина / ЈКП“ за да ја претвориш пријавата во дигитален налог и да испратиш еко-акција или аларм. Во корпоративниот профил прегледај го ESG влијанието, ваучерите и спонзорствата. „Ресетирај демо“ ги враќа почетните податоци.
